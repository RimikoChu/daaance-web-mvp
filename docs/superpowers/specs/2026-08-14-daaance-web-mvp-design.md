# Daaance! Web MVP 设计

## 目标

在没有硬件的情况下，稳定演示一段约 20 秒的完整训练：节拍提示、模拟动作、时序检测、即时纠错和训练结果。硬件接入不改变算法与 UI。

## 范围

- 中文单页 Web 应用，电脑和平板可用。
- 页面：首页、训练设置、训练中、训练结果。
- 固定编舞，不上传歌曲、不登录、不使用数据库。
- 默认四个模拟 Pod 均已连接。
- Accessibility 模式仅视觉与触觉可视化；Rhythm Coach 模式额外显示口令。
- 正确动作保持安静；只有超出容差的肢体显示错误反馈。

## 架构

- `MotionDataSource` 统一输出带肢体 ID 的 IMU 样本。
- `MockMotionDataSource` 根据固定编舞生成带可重复偏差的模拟峰值。
- `BLEMotionDataSource` 先保留接口和不可用状态，后续接 Web Bluetooth。
- 检测层计算加速度/陀螺仪运动能量、峰值时间和 timing error。
- 训练控制器以同一时间轴驱动 UI、提示和数据分析。
- 结果层汇总准确率、各肢体表现和一条规则生成的教练总结。

## 降级策略

BLE 未连接、浏览器不支持或数据中断时，用户可继续使用 Mock 模式完成演示。视频素材缺失时以同步舞蹈引导动画承载时间轴，不阻断训练。

## 验收

用户无需硬件即可在一次连续操作中完成设置、倒计时、约 20 秒训练并进入结果页；算法测试、生产构建均通过，刷新页面后仍可重新开始。
